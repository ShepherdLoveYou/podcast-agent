策划台
步骤 1

来源

每行一个链接。YouTube 视频可以先让它读一遍，之后的讨论会以内容纪要为依据；读一个一小时的视频大约要一分钟。

步骤 2

聊这一期

讲什么、从哪个角度讲、用哪种形式。固定的节目风格每期会自动加上，这里只需要聊这一期特有的东西。

步骤 3

本期策划

可以直接改。着重点会接在固定的节目风格后面，一起交给 NotebookLM。

步骤 4

生成

生成约十几分钟，会消耗一次音频配额。结束后会开出一个 PR，在 GitHub 里试听并合并才算发布。

打开 GitHub 手动触发

设置

GitHub 令牌只保存在这台设备的浏览器里，用来触发生成和查看进度。建议新建一个只对这个仓库生效的细粒度令牌，权限只开 Actions 的读写。不填也可以，用"打开 GitHub 手动触发"。
